PRIVACY & SECURITY

画像も文字も、
パソコンの外に出ません。

OCR のモデルは拡張の中に入っていて、WebAssembly でパソコンの中で動きます。契約書やレシート、社内の資料も安心して読み取れます。

  • OCR のための通信はありません画像・スクリーンショット・読み取った文字を、サーバーに送りません。
  • データを集めません個人情報も、利用の統計も、Cookie も使いません。
  • オフラインでも動きます入れたあとは、ネットにつながっていなくても使えます。
  • ソースコードを公開しています何をしているかは、だれでも GitHub で確かめられます。

求める権限と、その理由

どの権限も、パソコンの中での OCR のためだけに使います。

scripting見ているページに、範囲を選ぶ枠を出すため
サイトへのアクセス（全サイト）範囲選択を始めたときだけ、見えている画面を撮るため
offscreenOCR のエンジンを動かすため（Service Worker では動かせないため）
clipboardWrite / clipboardRead結果をコピーするため、コピーした画像をビューアで開くため
contextMenus右クリックのメニューに OCR を出すため
storage履歴・設定・クリーニングルールを保存するため

OCR の履歴は、このパソコンの中だけに保存します（chrome.storage.local）。設定とクリーニングルールは chrome.storage.sync に保存するので、Chrome の同期をオンにしている場合は、あなたの Google アカウントで Chrome が同期します。くわしくは プライバシーポリシー をご覧ください。

USE CASES

「この文字、コピーできたらなあ」
が、できます。

縦書きも、筆文字も、はんこも、斜めに撮った写真も。

縦書き

漫画のセリフを引用したい

縦書きの吹き出しを手で打たなくても、囲めばそのまま文字に。

筆文字

日本酒のラベルを記録したい

撮った写真からラベルの文字を読み取って、メモや共有に。

長い文章

新聞のコラムを残したい

縦書きは右から左へ。読む順番は自動で判断します。

消しゴム

請求書のはんこは読ませたくない

はんこや手書きのメモをなぞって消してから、残りを読み取り。

ゆがみ補正

斜めに撮った本のページも

四隅を合わせると、真上から見たように平らにしてから読みます。

PDF

文字を選べない PDF から

手元の PDF を開いて、ページを移って、ほしい所だけ。

HOW TO

使い方は、3 ステップ。

STEP 1

囲む

ほしい文字を、マウスで囲みます。

STEP 2

少し待つ

ブラウザの中で、数秒で読み取ります。

STEP 3

貼る

もうコピー済み。どこにでも貼れます。

ツールバーのアイコン、右クリック、または Alt + Shift + O で始められます

FEATURES

小さな拡張に、ひととおり。

読み取る

  • どのページでも範囲選択 OCR小さなボタンやリンクの文字も読めます
  • 縦書き・横書き読む順番は自動で判断
  • 画像ビューア手元の画像、貼り付けた画像、ページ上の画像を右クリックで
  • PDF ビューアページを移りながら、好きなページを読み取り
  • ゆがみ補正で選択NEW斜めに撮った紙面を、平らにしてから読む
  • 消しゴムNEWはんこやメモを消してから読む。Ctrl+Z で戻せる

整える

  • クリーニングルール正規表現で、コピーの前に結果を整える
  • 表やレシート同じ行の項目はタブ区切りに
  • ふりがなを除くルビは自動で取り除く
  • 読み間違いのくり返しを抑える同じ文字が続くノイズを切り、「ドドドド」のような本当のくり返しは残す

残す・速く

  • OCR の履歴前の結果を、もう一度コピー・編集・検索・削除
  • 並べて速く読む最大 4 行を同時に読み取り、長い文章も速く
  • モデルのキャッシュ2 回目からはすぐに始まります
  • 日本語・英語の画面ブラウザの言語に合わせて切り替え

## はじめに

[Chrome拡張「オフラインOCR」](https://chromewebstore.google.com/detail/offline-ocr/cfppiicaeemimcbodibggnnolckcpmpd) というブラウザ完結の日本語OCR拡張を作って、リリース後にプロモ用のショート動画をぽつぽつ公開してきました。

- [作った話（1本目の記事）](https://zenn.dev/lecto/articles/a2ee65243b02b3)
- [ストア素材・動画をHTML+CSS+Claudeで作った話（2本目）](https://zenn.dev/lecto/articles/3b1606a8ac859e)
- [作って公開してからちょこちょこ直した話（3本目）](https://zenn.dev/lecto/articles/0ff674ad00181f)

今回はその **動画の活動報告** です。ただ「宣伝しました、こんな数字でした」ではなく、**「OCR ってこういう使い方できますよ」を1本ずつ布教していく活動** としてやっていることをそのまま書いてみます。

![](https://static.zenn.studio/user-upload/0bd8bb8fb264-20260705.png)

見返すとよく分かるんですが、**最初のうちの動画は intro スライドがほぼ同じで、サムネだけでは何の動画か区別しづらい** ものが並んでいました。途中から「日本酒のボトル」「新聞の紙面」といった **その動画のテーマがひと目で分かるイラスト** を intro に差し込むようにして、シリーズの中でも「この回は何の話か」がサムネの段階で伝わるように少しずつ改善しています。

## 「宣伝」ではなく「困りごとに対する提案」として作っている

普段の仕事（Lecto）では、お客様やユーザーの困りごとを聞いてユーザーストーリーを組み立て、それを元に機能や方針を決めるということを日常的にやっています。「誰が」「何をしたくて」「今はどう詰まっているのか」を先に描いてから、プロダクトの答えを設計するアプローチです。

このアプローチが自分にとって自然になっていて、個人開発の宣伝活動でもそのまま同じ考え方でやりたい、というのが今回の話です。

つまり動画1本1本が、**「こういう困りごとありませんか？ → OCR ならこう解決できます」というユーザーストーリーの提案** になっています。売り込みじゃなくて、**「こういう使い道がありますよ」の布教** に近い感覚。

なぜかというと、**OCRっていう技術は、機能そのものより「何に使えるか」の方が伝わりにくい** んですよね。ラベルOCR、コマOCR、コラムOCR — 用途の解像度が上がるほど「あ、それ自分にも使える」が生まれる。だから作った側からユースケースを1つずつ具体的に提示していく必要がある。

## これまでに出したユーザーストーリー

だいたい **1〜2週間に1本のペース** で、拡張が対応する使い方を1つずつ動画化しています。1本の動画 = 1つの困りごとの解決策として組み立てています。

| 動画                     | 想定したユーザーストーリー                                                       |
| ------------------------ | -------------------------------------------------------------------------------- |
| **リンクの文字**         | リンクを _コピーしたいだけ_ なのに押すと飛んじゃう。押さずに文字だけコピーしたい |
| **漫画の縦書き吹き出し** | 気に入ったコマのセリフを引用したい。でも縦書きで手打ちは面倒                     |
| **崩し字の俳句**         | 気になった句を書き留めたい。でも崩し字は読みも書き起こしも大変                   |
| **日本酒のラベル**       | 銘柄を記録して友達に共有したい。でも縦書き＋くずし字の筆文字                     |
| **新聞の縦書きコラム**   | コラムの気になった一節を残したい。でも縦書きだから手打ちが面倒                   |
| **ポケカのテキスト**     | カードの効果テキストをコピーしたい。カード画像しかないし、手打ちは辛い           |

こう並べると、**全部「〜したいけどOCRがないと・・・しんどい」場面** です。動画を作る過程で「拡張機能がこのユースケースに耐えられるか」の検証にもなっていて、実際、動画作りで見つけたバグから v0.6.2 の修正リリースが生まれました。

![](https://static.zenn.studio/user-upload/30b457a655b8-20260705.png)

**布教活動が兼プロダクト検証になっている** のは、一人で回すサイクルとして相性がいいなと感じています。

### 数字から読み取れたこと

- **共感軸のユースケースは伸びる**：一番伸びたのは **リンクの文字（646）**。「押しちゃう問題」は日常的な小さなイライラで、共感のフックとしていちばん強かった。
- **意外性軸は届く相手が違う**：崩し字（69）や日本酒（116）は数字は控えめだけど、届いた人には「そんなことできるんだ」の驚きが刺さる。数字より **届いた人の質** で価値を測るタイプ。
- **ロング動画はストア導線で長く効く**：ロング（1,345）は Chrome Web Store のプロモ動画欄に貼ってあるので、**時間で積み上がる**。「拡張を見つけた人が動画も見て納得する」というサブ動線として機能している。

## 続けている理由

普段の仕事でも、**「お客様の課題からプロダクトを組み立てる」** をずっとやっていて、それがしっくり来る考え方だと自分では思っています。個人開発でも、同じ姿勢で「使う人の困りごと → OCR での解決策」という1本の線を作り続けたい。

宣伝という枠より、**ユースケースの引き出しを一緒に増やしていく活動** の方が自分にとって続けやすいですし、届く相手にとっても「機能」ではなく「自分の困りごとが解決される話」として受け取ってもらえる気がしています。

## 次に取り上げたい困りごと

まだ引き出せていないユースケースがたくさんあります:

- **おみくじ**：結果を写真で撮って友達に送りたい、でも文字だけ抜き出したい
- **居酒屋メニュー**：気になった料理名をメモしたい、でも筆文字の縦書きは打てない
- **書道作品**：SNS投稿で作品の文字を紹介したい、でも読める人が限られる
- **名刺**：もらった名刺の縦書き会社名・役職を連絡先に登録したい

引き続き月に1〜2本のペースで、**「1本の動画 = 1つのユーザーストーリー」** の方針で淡々と続けようと思います。

## おわりに

拡張機能側もアップデートを続けていて、直近では **OCR履歴機能（v0.7.0）** を入れました。「コピーしたやつ、あとからもう1回使いたい」を自分自身が感じたところから作った機能です。作った側自身も1ユーザーで、困りごとから機能を組み立てるサイクルは、個人開発でも変わらない。

次回もまた、新しいユースケースを1つ増やしたら書きに来ます。

OCRって、まだ言葉になっていないユーザーストーリーが本当にたくさん眠っている領域だと感じています。「縦書きの一節を残したい」「ラベルの文字だけ拾いたい」「引用したいけど手打ちは辛い」— 困りごとの形は人によって全然違って、抱えている本人にしか分からない。

だから、1本1本の動画は、**知らないだけで実は困っている誰か** に届けるための小さな旗のつもりで作っています。「あ、これ自分に必要なやつだ」と1人でも気づいてもらえたら、そこから初めてこのツールはその人にとって意味を持ちはじめる。

拡張機能自体は、ただストアに置いてあるだけでは何も起きません。「あなたのその困りごと、もしかすると解決するかも」と伝わって、はじめて誰かの手に渡る。**まだ届いていない誰かに届けにいくこと** が、作った側にできる続けるべき仕事だと思っています。

まだ知られていない使い道は、きっとこの先にもたくさんある。1本ずつ、届く人に届けにいきます。

オフラインOCR — どこにも通信しない安全な範囲選択OCR

画面上の好きな場所をマウスで選択するだけで、テキストを読み取ってクリップボードにコピーします。
OCR エンジンには国立国会図書館 (NDL) が開発した NDLOCR の軽量版を採用しており、日本語テキストの認識に優れています。
すべての処理はあなたのブラウザ内で完結。インターネット接続は不要で、画像やテキストが外部サーバーに送信されることは一切ありません。

■ 主な特徴

・完全オフライン — データは一切外部に送信されません
・ワンクリックで使える — 範囲を選択するだけで自動コピー
・日本語テキストに特化 — 国立国会図書館の OCR 技術をベースにした高精度な認識
・3つの起動方法 — ツールバーアイコン / キーボードショートカット / 右クリックメニュー
・正規表現クリーニング — カンマ削除や不要なスペースの除去など、コピー前に自動整形。自分だけのルールを自由に追加でき、請求書の金額処理など実務に合わせたカスタマイズが可能
・画像ビューアー — ローカル画像やクリップボードの画像を開いて OCR。拡大して範囲選択も可能
・多言語対応 — 日本語・英語の UI を自動切替

■ 使い方

1. 拡張機能のアイコンをクリック（またはショートカットキー）
2. OCR したい範囲をドラッグで選択
3. 数秒待つと認識結果が自動でクリップボードにコピーされます

💡 画像ビューアー機能
　 ローカルの画像ファイルやクリップボードの画像も OCR できます。
　 ・拡張機能のポップアップから「画像を開く」「クリップボードの画像を開く」
　 ・Web ページ上の画像を右クリック →「ビューアーで画像を開く」
　 ビューアーでは画像を拡大して範囲選択したり、画像全体をまとめて OCR できます。

■ こんな場面で便利

・PDF や画像内のテキストをコピーしたいとき
・請求書や帳票の数値を素早く取り出したいとき
・スクリーンショットから文字を起こしたいとき
・社外秘の文書を外部サービスに送りたくないとき

■ プライバシーについて

オフラインOCR は外部サーバーとの通信を一切行いません。
OCR エンジン (ONNX Runtime Web) とモデルはすべて拡張機能に内蔵されており、ブラウザ内で完結して動作します。
個人情報や画像データが収集・送信されることはありません。

■ 技術仕様

・OCR エンジン: NDLOCR-Lite (国立国会図書館 OCR の軽量版)
・検出モデル: DEIM (FP32)
・認識モデル: PARSeq (FP32)
・推論ランタイム: ONNX Runtime Web (WebAssembly)
・対応言語: 日本語（横書き）
・動作環境: Chrome 116 以降

■ 謝辞

本拡張機能の OCR エンジンおよびモデルは、国立国会図書館 (NDL) が研究・開発・公開した NDLOCR をベースにしています。
高精度な日本語 OCR 技術をオープンに公開してくださった国立国会図書館に深く感謝いたします。

■ バージョン履歴

v0.8.1
・多行ページの OCR を高速化。DEIM で複数行を検出した場合の PARSeq 認識を同時 4 行の並列実行に変更（新聞コラム、レシート、複数段落のドキュメントで体感短縮）
・出力順は従来と同一。1〜2行のキャプチャでは影響なし

v0.8.0
・PDF ファイルの OCR に対応。ポップアップの「PDFを開く」から、ローカルの PDF をビューアーで開いてページごとに OCR できます（パスワード付き PDF は非対応）
・ビューアーにページナビゲーション（◀ / ▶ ボタン、ページ番号表示、← / → キー）を追加
・OCR 履歴には `filename.pdf#p2` 形式でページ番号を残すので、どの PDF のどのページから取ったか後から確認可能
・PDF もすべてローカルで描画・OCR し、通信ゼロの方針を維持

v0.7.1
・小さな範囲を選んで OCR したときに、認識結果の末尾に「1」の繰り返しなど意図しない文字が混入する不具合を修正
・上下ぎりぎりに写り込む隣接行の文字断片がノイズの原因だったため、パディング色を枠全体の多数派から取得＋本文行の帯抽出、の2つを追加

v0.7.0
・OCR履歴機能を追加。コピー結果を自動でPC内に保存し、あとから再コピー・編集・削除・検索ができます（データは外部に送信されません）
・ポップアップ／オプションページから「履歴を開く」で一覧ページにアクセス

v0.6.2
・v0.6.1 でロールバックしていた v0.6.0 の不具合を修正し、「ふりがな自動フィルタ」「小さな選択範囲OCR」の機能を再有効化

v0.6.1
・v0.6.0 で報告された不具合（短い英数字をOCRすると、結果の末尾に「1」や「9」が大量に並ぶ問題）への暫定対応として、v0.5.0 相当の挙動にロールバック

v0.6.0

・範囲選択の青枠がOCR画像に混入する不具合を修正し、検出精度も向上
・デバッグモードを追加（OCRに渡される直前のクロップ画像を保存・表示）
